# Male illustration asset rename map

This bundle mirrors the structure of `ExerciseIllustrationsDummy.xcassets`, but every asset name has been renamed from `_dummy_` to `_male_`.

## Asset catalog path
`workouttracker/Resources/ExerciseIllustrationsMale.xcassets`

Why this file lives here:
It belongs next to the app's other bundled resources so Xcode includes it in the main target the same way as your current illustration assets.

## String rename rule
- `ExerciseIllustrationsDummy.xcassets` -> `ExerciseIllustrationsMale.xcassets`
- `exercise_<slug>_dummy_v1` -> `exercise_<slug>_male_v1`
